# Dhuan Cafe - Desi Meets Modern

A stunning premium cafe website showcasing traditional Pakistani chai culture with modern coffee shop aesthetics.

## 🎨 Design System

### Color Theme - Chai & Spice
- **Dark**: `#3D1F0D` (navbar, footer, hero backgrounds, dark sections)
- **Main**: `#C17A3A` (buttons, accents, links, highlights)
- **Light**: `#E8C49A` (hover effects, borders, badges, subtle text)
- **Background**: `#FDF8F5` (page background, light cards)
- **Card Dark**: `#2A1208` (dark product cards)

### Typography
- **Headings**: Josefin Sans (weights 300, 400, 600) - ALWAYS UPPERCASE
- **Body**: Nunito (weights 300, 400, 600)

## 🚀 Features

- **Hero Section**: Dark moody aesthetic with floating product elements
- **Menu System**: Interactive category tabs with chai, coffee, and house specials
- **About Section**: Storytelling with animated statistics
- **Contact Forms**: Functional contact and reservation forms
- **Responsive Design**: Mobile-first approach with smooth animations
- **Modern Animations**: Framer Motion powered micro-interactions

## 🛠️ Tech Stack

- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS with custom configuration
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Google Fonts (Josefin Sans, Nunito)

## 📦 Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```
3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```
4. Open your browser to `http://localhost:5173`
